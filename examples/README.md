# Examples

Worked examples of the kind of analysis Prism is built for — each one real data, the exact
calls that produced it, and a self-contained visualization you can open in a browser.

| Example | What it shows |
|---|---|
| [intermittent-fasting-glycemic-control](./intermittent-fasting-glycemic-control/) | Deep research meta-analytics on a whole topic, then narrowed to one claim — the claim lane, the stance split, pooled effects read verbatim, and how to swing the lens to any other angle with one call. |

Each folder holds `index.html` (the visualization), `README.md` (the commands to reproduce and
to focus other angles), and `data.json` (the raw retrieved payload, kept for audit).
