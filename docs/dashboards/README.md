# Dashboards built with the Prism MCP

Each dashboard below was built by an assistant from **one brief**, connected live to the Prism MCP: it chose its
own tools, built the page, checked it with Prism's `check_report`, and handed back working HTML. Every page
records the brief, the tool calls in order, and the checks the finished page passed.

| Dashboard | Use case | Built by | Prism calls | Live |
| --- | --- | --- | ---: | --- |
| [Air pollution: where it is reported, studied and patented](air-pollution-geo/README.md) | GEO intelligence (world map, India states, cities) | Claude | 19 | [open](https://fliarbi.com/demo/docs/prism-dashboards-3bb43e4c/air-pollution-geo/) |

Maps use `world_india_official.geojson` and `india_states_official.geojson` (in each dashboard folder), which draw
India with its official outline.
