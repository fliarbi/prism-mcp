# Topic intelligence

Topic intelligence reports, one per topic, built from MCP calls: coverage and tone, areas of activity and the top tags behind the themes, places on world and India maps, people and organisations, causes and impacts quoted from the reports, two sections drilled into, themes over five years, three reader views chosen by domain, the nine research exploration methods with in-depth readings, and a month-by-month reading. Each page has a written analysis.
